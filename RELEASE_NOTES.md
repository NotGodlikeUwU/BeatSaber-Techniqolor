# Techniqolor 0.1

Native Quest port of Technicolor by Aeroluna for Beat Saber 1.40.8_7379 / Scotland2.

- Renamed the mod, menus, mod ID, library and configuration file to Techniqolor.
- Set the game-facing and QMOD version to 0.1.
- Translated the README and headset checklist into English.
- Includes rainbow lights, notes, walls, bombs, sabers, arcs, particles and background settings.

Validation: ARM64 build, 25 color logic checks and QMOD identity/architecture/hash verification passed. Headset startup, visuals, performance and multiplayer are still unverified; this is an experimental release.

Install Techniqolor-0.1.qmod with a QMOD installer for modded Beat Saber 1.40.8_7379. Dependencies are declared in the package. If the earlier Technicolor Quest QMOD is installed, remove it before installing this renamed mod.
